# flutter-tic-tac-toe

A minimal tic-tac-toe app in Flutter.

## Goal

Two players, one device. 3x3 grid, alternating turns, win/draw detection, reset.

## Scope

In:

- 3x3 board, tap to place
- Turn indicator
- Win and draw detection
- Reset button

Out:

- AI opponent
- Networked play
- Accounts, persistence, animations

## Stack

Flutter, single package. No state management library — plain `setState`.

## Run

```sh
flutter pub get
flutter run
```
